# Zeus VPN 1.1.0.2

## What's new

- **App icons in the per-app picker (Android).** The app list in Settings → Full VPN apps now shows each app's icon next to its name, so you can find apps you don't remember by name. Apps without a usable icon show a neutral placeholder.

Everything from 1.1.0.1 is still on board:

- **Fixed Full VPN mode on the desktop** (routing-loop fix: the VPN server's addresses stay off the virtual adapter's routes on every platform).
- **Per-app tunnelling on Android:** Settings → Full VPN apps — tunnel only the apps you choose, or everything except a few.

## Downloads

| Platform | File |
|---|---|
| Windows 10/11 | `ZeusVPN-amd64-installer.exe` (or the portable `ZeusVPN.exe`) |
| Android 7+ | `ZeusVPN-android-arm64-v8a.apk` (most phones), `-armeabi-v7a` or `-universal` |
| Linux x86-64 | `zeusvpn_1.1.0.2_amd64.deb` or `ZeusVPN-linux-amd64.tar.gz` |
| macOS (beta) | `ZeusVPN-macos-universal-beta.dmg` |
| iOS / iPadOS (beta) | `ZeusVPN-ios-unsigned-beta.ipa` |

> The **macOS and iOS builds are still beta** and have not been fully tested on this release; the Windows, Linux and Android builds are stable. If something doesn't work, please open an issue with the log (Settings → View logs).
